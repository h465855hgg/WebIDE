# Agent 工作台 2.0：把「能连」变成「能用」

> 分支：`feature/acp-agent-client`
> 代码：`app/src/main/java/com/web/webide/ui/editor/acp/`
> 本文记录这次改造的产品判断、架构取舍与后续路线。

---

## 1. 什么才算「完美的 Agent 面板」

不是把功能堆满，而是四条闭环：

| 闭环 | 含义 | 反例（改造前的面板） |
| --- | --- | --- |
| **不丢** | 会话、草稿、失败现场都能找回 | 时间线只在内存里，换个 Agent / 重启就没了 |
| **可控** | 权限、停止、回滚、成本都看得见 | 只有一个「自动授权」开关；token 完全不可见 |
| **可读** | 消息、思考、计划、工具、diff 有层级 | 全部是 8dp 圆角的灰卡片，diff 只是一段文本 |
| **可迁移** | 换 Agent / 模型 / 供应商不锁死数据 | 历史全在 Agent 自己的 session 里，客户端是空壳 |

按「层」拆，一个 Agent 面板至少有六层：

1. **连接层**：协议握手、传输、环境探测、安装升级。
2. **会话层**：本地持久化、恢复、分叉、搜索、导出、工作区隔离。
3. **权限层**：工具分级、记住规则、只读模式、审计。
4. **观测层**：token、上下文占用、轮次、工具次数、错误与耗时。
5. **表达层**：Markdown、代码块、思考、计划、工具卡片、diff、文件跳转。
6. **个性化层**：模型/供应商、记忆、行为指令、MCP、附件。

原分支第 1 层做得相当扎实，第 2–6 层基本是空缺。这次先补 2/3/4 层，并把 5 层的地基换掉。

## 2. 本次改造

### 2.1 会话层：本地优先，而不是 Agent 优先

新增 `AcpSessionStore`：

- 路径：`filesDir/acp_sessions/<workspaceHash>/`
  - `index.json`：会话索引（标题、摘要、时间、轮次、token、置顶）
  - `<sessionHash>.json`：完整时间线（user / agent / thought / notice / plan / tool + diff）
- 工作区用工作目录的 SHA-256 前 16 位隔离，换项目不会串历史。
- 原子写（`.tmp` + rename）；索引损坏时从会话文件自动重建。
- 防抖落盘：流式输出期间最多 900ms 写一次；回合结束、切会话、退出时强制保存。

配套能力：

- **面板打开即恢复上次对话**（即使 Agent 没连、离线也能读）。
- **本机记录 / Agent 会话双列表**：搜索标题、摘要、正文；重命名、置顶、删除、导出 Markdown。
- **重连优先恢复**：`initialize` 后先试 `session/load`，失败才 `session/new`，避免「一重连就失忆」。
- 导出写到项目 `.webide/exports/`，文件树里直接可见。

边界：

- 本地记录是**展示层副本**，不替代 Agent 的上下文；离线回放会进入只读，点「继续此会话」才会让 Agent 接管。
- Agent 不支持 `session/load` 时，只能看，不能续写——这是协议限制，不假装能续。

### 2.2 权限层：从布尔值到策略

新增 `AcpPermissionController`，四种级别：

| 级别 | 行为 |
| --- | --- |
| `ASK` | 每个请求都弹卡片 |
| `SMART` | `read/search/think` 自动放行，写盘/执行仍询问（默认） |
| `AUTO` | 全部自动放行（明确标注危险） |
| `READ_ONLY` | 拒绝写文件、删文件、移动、执行命令 |

另外：

- **按工具类型记忆**「总是允许 / 总是拒绝」，持久化在 `acp_permissions`。
- 旧版的 `auto_approve` 布尔值会自动迁移到 `AUTO` / `SMART`，老用户设置不丢。
- 每次决策记入审计（类型、标题、结果、原因），设置页可查看并清空规则。
- 自动裁决会优先选 `allow_once` / `reject_once`，把「永久放行」留给用户显式选择。

### 2.3 观测层：token 与上下文

ACP 不要求 Agent 上报用量，所以 `AcpUsageTracker` 采用双轨：

- **估算**：CJK 字符 ≈ 1 token/字，其余 ≈ 1 token/3.6 字符；上下文占用按时间线全文累计。
- **上报**：从 `session/prompt` 响应或其 `_meta.usage` 读取 `inputTokens/outputTokens/totalTokens`，兼容 snake_case；用「单调递增视为累计、否则视为本回合」的启发式合并。
- 上下文窗口按模型名匹配（Claude 200k、Gemini 1M、Qwen 256k、DeepSeek 128k…），未知模型保守给 128k。
- 界面统一带 `≈`，并标注「客户端估算 / Agent 上报」，不把估算值伪装成账单。

展示位置：

- 输入框上方的细进度条 + `≈12.4k / 128k`；
- 「会话统计」面板：输入/输出、轮次、工具调用、模型、本地存储占用；
- 上下文 ≥85% 时输入区上方出现警告条，可一键新建会话。

### 2.4 表达层：换掉手写渲染

- 消息正文改用 `multiplatform-markdown-renderer`（标题、列表、表格、引用、链接、代码块）。
- 长按 Agent 消息复制全文。
- Diff 卡片新增「全屏 Diff」：复用编辑器已有的 `DiffViewer`（SoraEditor + 对齐 diff + 并排/统一视图），以只读方式打开，避免查看历史时误改磁盘。
- **工具调用里的文件路径可点击**，直接跳到编辑器对应行；失败的工具卡片自动展开；完成的卡片显示客户端测得的耗时。
- 空状态给出三个可直接试的任务，而不是一句说明。

### 2.5 输入体验：中文输入法与键盘

原来的浮层是固定 340×460，`imePadding` 只作用在输入行内部，软键盘一弹就把面板盖住——这是「全拼打不出字 / 看不到候选」的根因之一。

现在：

- 输入框使用 `TextFieldValue`，保留 IME composition，不在每次输入时重建 String。
- 输入框默认单行，输入区右侧提供「半屏 / 全屏」两种展开输入；全屏是独立 Dialog，带自己的发送/关闭。
- 面板顶部是双层结构：第一层窗口管理（最大化 / 收起 / 关闭），第二层会话管理（搜索 / 历史 / 任务 / 新建）。
- 面板宽高与停靠侧落盘，下次打开保持用户习惯。

### 2.6 技能（原记忆与行为）

ACP 没有 system prompt / skills 协议，所以用「项目文件 + 首轮清单注入」实现：

- **技能文件**：`.webide/skills/*.md`，每个文件名称 + 描述 + Markdown 正文，文件树里可直接编辑。
- **技能管理**：面板 `⋮ → 技能管理` 里新建 / 编辑 / 删除，开关「新会话注入技能清单」。
- **首轮注入**：新会话第一条 prompt 前只拼「技能名 + 描述 + 路径」清单，Agent 按需读取文件；`session/load` 重放历史时客户端会裁掉前缀，时间线只显示用户原文。
- **任务清单**：Agent 的 `plan` 更新渲染成清单页（进度、逐项状态），入口是输入框右上角「任务清单」文件夹标签。

### 2.7 模型与供应商

- **模型/模式记忆**：`session/set_config_option` 的选择按 Agent 持久化；新会话建立后自动恢复上次选择的模型、模式、思考等级，不用每次重选。
- **环境变量**：每个 Agent 可配置多行 `KEY=VALUE`（如 `ANTHROPIC_API_KEY`、`OPENAI_BASE_URL`），启动时注入 Agent 子进程；设置改动后 `isConnectedWith` 会判定为「未连接」，提示重连。
- **自定义供应商**：选择 Custom 预设 + 自定义命令 + 环境变量即可接入任意兼容 ACP 的 Agent 或中转端点。
- **认证**：保留 ACP `authMethods` 的自动尝试与「重新登录」入口。

### 2.8 会话内搜索与消息操作

- **会话内搜索**：按关键词扫当前时间线的用户消息、Agent 回复、思考、计划、工具输出；结果带上下文摘要并高亮关键词，点击跳回时间线并高亮该条 2.4 秒。
- **失败重试**：最后一条用户消息之后还没有 Agent 产出时（报错 / 超时 / 中断），用户消息长按可「重新发送」，会清掉尾部错误提示再发一次。
- **用这条开新会话**：任意用户消息都能「用这条开新会话」——新建 Agent 会话后把这条文本作为首轮 prompt，适合「上一个会话已经跑偏，想干净重开」。
- **复制**：用户与 Agent 消息长按复制全文。
- **诚实的边界**：ACP 没有上下文回滚 / 任意点分叉能力，所以「编辑后重发」和「从任意消息真正分叉」没有做——它们需要 Agent 侧支持，客户端硬做会给出错误的上下文语义。

### 2.9 MCP 服务器

- `MCP 服务器` 管理本地命令（stdio）或远程地址（HTTP/SSE）两类 MCP 服务器，支持启用/停用、编辑、删除。
- 配置在 `session/new` 与 `session/load` 时通过 `mcpServers` 下发；Agent 负责拉起进程 / 建立连接。
- 环境变量与请求头用多行 `KEY=VALUE` 编辑。
- 修改后需要新建（或重新加载）会话才会生效，界面已写明。

### 2.10 UI 布局与交互（重做）

自上而下：

1. **双层头部**：第一层窗口管理（最大化 / 收起 / 关闭）；第二层会话管理（名称 + 红绿状态点、搜索、历史、新建、`⋮` 里的设置/技能/MCP）。
2. **顶部状态条**：上下文占用进度 + `≈tokens / window`（点击进统计）；权限级别胶囊（点击直接进设置「权限」页签）。
3. **时间线**：参考 Operit / DeepSeek Harness——用户右侧彩色气泡；Agent 回复是带头像的独立卡片（Markdown + 复制动作）；思考 / 工具调用是缩进的 24–28dp disclosure 行，点开出详情卡；轮次 10–12dp、流程行 6dp；底部有「正在处理…」呼吸提示和回到底部按钮。
4. **输入区上方**：模型、模式两个胶囊，分别弹 DropdownMenu（模型含思考等级/参数，模式只含 mode），不是 BottomSheet。
5. **输入框**：默认单行；输入卡片右上角外侧有两个文件夹标签式入口——任务清单、全屏输入（全屏是独立 Dialog）；中文输入法安全。

其他：

- **切换模型/模式时的 IME**：菜单打开期间冻结面板尺寸，关闭菜单后再防抖 260ms 才响应键盘显隐，避免界面来回弹。
- **收起后的 FAB**：使用 Surface 的 `onClick`；可拖动，松手保持完整可见，停留 3 秒自动吸附侧边并半隐藏；位置会记住；展开动画从 FAB 角落开始。
- **统计面板**：去掉右上角关闭/返回按钮，靠下滑或系统返回关闭。
- **Agent 设置**：整屏 Dialog + 三个页签（Agent / 权限 / 诊断）；诊断页支持「复制诊断」和「保存到项目 `.webide/logs/`」。
- **登录**：点击只表示「登录请求已发送」，不再乐观显示「已登录」；结果以 Agent 终端输出/日志为准。
- **开关逻辑**：设置里的「AI 编程助手」只决定功能是否启用；面板可见性是本次编辑会话的临时状态，默认关闭。
- **文案**：设置/技能/MCP 里大段说明已删掉，只保留控件和必要提示。

## 4. 已知边界

- **离线回放不可续写**：Agent 的上下文在它自己的进程里，客户端只能看。
- **token 是估算**：没有统一 tokenizer；只有 Agent 主动上报时才是真实值。
- **权限只按工具类型**：尚未支持路径/命令白名单（例如「只允许写 `app/src`」）。
- **深搜成本**：会话搜索会按需读取会话文件；几百条以内可接受，更多需要倒排索引。
- **API Key 是私有 prefs 明文**：不上日志、不出 filesDir，但没有接入系统 Keystore；共享设备需自行注意。
- **没有模型目录 / 价格表**：模型列表仍由 Agent 的 configOptions 决定，成本只能看 token 估算。
- **草稿未跨进程持久化**：旋转不丢，杀进程会丢。
- **MCP 配置是全局的**：不按项目隔离；同一台设备上的项目共享同一份服务器列表。

## 6. 验证

```sh
./gradlew :app:compileArm64-v8aDebugKotlin
./gradlew :app:assembleArm64-v8aDebug
```

真机建议按以下顺序过一遍：

1. 连一个 Agent，发一条消息，杀进程重开面板：应看到本地记录。
2. 断网/断连后打开历史：应能读全文，发送被禁用，点「继续此会话」后恢复。
3. 把权限设为「只读」，让 Agent 改文件：应被拒绝并留下审计。
4. 让 Agent 改一个文件：diff 卡片点「全屏 Diff」，应打开编辑器同款 diff。
5. 打开输入法打中文：面板应上移而不是被键盘盖住。
6. `⋮ → 记忆与行为` 写两条约定、选「先计划」→ 新建会话发一句：时间线只显示原文，Agent 按计划走。
7. 设置里填一条环境变量 → 保存 → 确认提示重连。
8. `MCP 服务器` 添加一个 stdio 服务器 → 新建会话：Agent 日志/工具列表里应出现对应 MCP 工具。
9. 发一条会失败/被中断的消息 → 长按用户消息「重新发送」；再长按任一提问「用这条开新会话」。
10. 点顶部上下文条 → 统计面板（应无右上角返回按钮）；点模型/模式胶囊 → 两个独立面板。
11. 点「收起」→ 拖动悬浮球上下移动、松手吸附左右边缘并半隐藏；再点开。
12. 设置里关闭「AI 编程助手」→ 返回编辑器：面板不应再自动出现。
